# Proyecto de Cátedra Fase 2 - DMD941

## Data Warehouse Superstore

Este repositorio contiene la implementación de la Fase 2 del proyecto de cátedra de la materia Datawarehouse y Minería de Datos.

El objetivo de esta fase es implementar el proceso de Data Warehouse a partir del archivo fuente Superstore DMD941, aplicando un proceso ETL para cargar los datos en un modelo dimensional tipo esquema estrella.
